# E-Wallet System

A simple electronic wallet system built using Java and Object-Oriented Programming (OOP).

## Features
- Create account
- Deposit money
- Withdraw money
- Transfer balance
- Check wallet balance

## Technologies Used
- Java
- OOP Concepts

## Project Structure
```bash
eWalletSystem/
```

## How to Run
1. Open the project in IntelliJ IDEA
2. Run the main file
3. Use the console menu
